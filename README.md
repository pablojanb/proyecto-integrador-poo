[![My Skills](https://skillicons.dev/icons?i=cs,net,mysql)](https://skillicons.dev)
## Instalación y configuración
1. Clonar el repositorio
```bash
git clone https://github.com/pablojanb/proyecto-integrador-poo.git
```
2. Navegar a la carpeta del proyecto
```bash
cd proyecto-integrador-poo/clubdeportivo
```
3. Crea tu base de datos MySQL

4. Crear un archivo `appsettings.json`

5. Copiar el contenido del archivo `appsettings.ejemplo.json` al nuevo archivo y adaptar las variables para tu entorno.

6. Ejecuta
```bash
dotnet run
```
